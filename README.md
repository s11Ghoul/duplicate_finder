# Phishing Site Detector

Автоматизация поиска фишинговых сайтов через Google с проверкой редиректов.

## Установка

```bash
# Python 3.10+
pip install -r requirements.txt
```

Также необходим [Google Chrome](https://www.google.com/chrome/) и соответствующий [ChromeDriver](https://chromedriver.chromium.org/).

> Selenium 4.15+ автоматически управляет ChromeDriver через `selenium-manager`, поэтому отдельная установка ChromeDriver обычно не нужна.

## Использование

### Интерактивный режим

```bash
python phishing_detector.py
```

Скрипт запросит название бренда и страну.

### Аргументы командной строки

```bash
python phishing_detector.py --brand 1xbet --country Germany
python phishing_detector.py --brand 1xbet --country DE --output results.csv
```

### Список поддерживаемых стран

```bash
python phishing_detector.py --list-countries
```

## Как это работает

1. Пользователь подключает VPN к нужной стране
2. Скрипт формирует 6 поисковых запросов:
   - `{бренд}`
   - `{бренд} casino`
   - `{бренд} bonus`
   - `{бренд} login`
   - `{бренд} download app`
   - `{бренд} download apk`
3. Для каждого запроса выполняется поиск в Google с геопривязкой
4. Для каждого из топ-10 результатов:
   - Открывает сайт
   - Ищет и кликает кнопку логин/регистрация
   - Фиксирует финальный URL после редиректа
   - Если домен изменился — помечает как подозрительный
5. Результаты сохраняются в CSV

## Результаты

CSV файл с колонками:

| Страна | Запрос | Позиция | URL сайта | Редирект URL | Подозрительный |
|--------|--------|---------|-----------|--------------|----------------|

## Обработка CAPTCHA

При обнаружении CAPTCHA от Google скрипт автоматически останавливается и ждёт, пока пользователь решит её вручную в открытом окне браузера. После решения — нажмите ENTER в терминале для продолжения.

## Поддерживаемые страны

95+ стран. Используйте `--list-countries` для полного списка. Можно указывать название страны (`Germany`) или двухбуквенный код (`DE`).
